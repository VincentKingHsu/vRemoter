vRemoter 1.1.1 · macOS

遥控器不只负责播放，也能控制你的输入。

用 X6 或 Chromecast Voice Remote 控制豆包语音输入，把遥控器麦克风与 MacBook 麦克风混合起来，再把电视按键映射成真正有用的 Mac 操作。

首次安装（含驱动） 查看源码 ↗

适用于 macOS 12 及以上版本。当前针对豆包输入法。

1.1.0 新功能

把电视按键，换成你的 Mac 快捷键。

方向、确认、返回、Home、YouTube、Netflix、信源、音量等按键都可以按型号配置。映射启用时，vRemoter 会拦截原始动作，只发送你选择的新操作。

  • 内置方向键、Return、Escape、系统音量、Spotlight 等常用操作
  • 可以直接录制自己的键盘组合键
  • 设置跟随型号，更换同型号遥控器无需重配

已验证型号

两款遥控器，各自保留自己的设置。

X6 与 Chromecast Voice Remote 可以同时连接。支持按型号识别，不绑定你手上的某一只实体设备。

X6 Remote

VID 1D5A · PID C081

语音、正面按键、背面键盘与鼠标透传

Chromecast Voice Remote

VID 18D1 · PID 9450

短按切换、长按说话与完整按键映射

支持范围以这里列出的 VID/PID 为准，不代表所有 Chromecast 遥控器型号。X6 鼠标模式切换键由设备固件内部处理。

双麦语音输入

说话时，不必决定站在哪一支麦克风旁边。

vRemoter 把遥控器和 MacBook 麦克风混合成豆包可识别的 vRemoteDr 2ch。语音触发键默认使用 Option，也可以改为 Command、Control、Shift 或 Fn。

01

短按切换

第一次打开，第二次关闭。

02

长按说话

按住期间录音，松开结束。

03

交叉控制

电脑按键与遥控器可以互相开启和关闭。
