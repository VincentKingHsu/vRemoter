# vRemoter UI v1 冻结记录

- 冻结日期：2026-08-09
- 冻结状态：用户已确认采用，后续产品界面以此稿为基线
- 设计方向：Studio Mixer / 紧凑型双麦混音台
- 生成页面：8 个代表性状态

## 已锁定的核心设计

- MacBook 麦克风、X6 遥控器麦克风、混合输出位于同一张三通道卡片。
- 混合输出与两路输入保持同一视觉语言，但使用更重的琥珀色层级。
- 前两路使用“静音 / 独奏”；独奏时另一输入通道联动变暗。
- 混合输出的“两路已合并”是状态，不是按钮。
- 主界面只呈现高频真实状态；登录启动与调试工具保留在菜单栏。
- 底部检查区覆盖豆包输入设备、驱动、X6 HID/BLE/语音流及三类权限。
- X6 名称固定为“X6 遥控器麦克风”，并预留“购买遥控器”链接位置。
- 产品展示名统一使用 `vRemoter`；系统音频设备名保留 `vRemoteDr 2ch`。
