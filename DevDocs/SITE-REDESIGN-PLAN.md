> 状态：**proposal 待大徐老师拍板**。拍板后在 `vibecoding/website-v2/` 副本实施，本地预览审过再上服务器。

## 一、诊断依据（impeccable = pbakaus/impeccable）

原则出处：`skill/reference/layout.md`、`polish.md`、`bolder.md`。

1. **拓扑匹配内容**（layout.md "Does the topology match the content?"）：一个区只装一个主题。映射区塞两个主题 = 1.2.3 上线后"怪胎感"的根源。
2. **Squint test**：眯眼主次有序。hero 区左文高度匹配右图 = 全站标杆节奏。
3. **Rhythm**：图文方向行间交替（Z 形），间隔松紧成节奏。
4. **Amplify what the system already owns**（bolder.md）：灯光效果只用品牌绿放大，不发明新颜色。
5. **Give it its own rhythm**（bolder.md）：系统级动作区作为滚动中的 peak，用一次更亮的处理。

## 三、系统级动作区（核心新设计）

位置：映射区之后，逻辑顺承（键→快捷键 → 键→系统动作）。

布局（镜像行，Z 形）：
```
左：菜单特写图 vremoter-system-actions-1.2.3(-en).png（464×308 原比例）
右：eyebrow「1.2.3 新增」+ H2 + 一句话 + 三张动作卡（竖排，复用 voice-modes 卡样式）
```

文案（纠偏版）：
- H2：**锁屏、睡眠、切换应用——都从沙发出发。**
- 一句话：任意遥控器按键都能指定为系统级动作，映射菜单里两下就配好。
- 三卡：
  - 锁屏 · 起身就走，按一下立刻锁屏
  - 睡眠 · 整台 Mac 安静下来，明早再战
  - 切换应用 · ⌘Tab 手感，连按挑选，停手一秒落地

本区作为滚动 peak，用全站最亮的氛围处理。
